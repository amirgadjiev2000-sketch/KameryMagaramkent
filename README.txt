Готовая веб-версия.

Главный файл: index.html

Чтобы открыть с телефона и с любого устройства постоянно:
1. Загрузите файл index.html на любой статический хостинг: Netlify, Vercel, GitHub Pages или обычный сайт/сервер.
2. Открывайте выданную ссылку в браузере.

Важно: данные сохраняются в браузере устройства через localStorage. Если открыть ссылку на другом телефоне/компьютере, там будет отдельное локальное хранилище. Для передачи актуального состояния используйте кнопку «Файл для начальства» — она скачает HTML со встроенными текущими данными.
